ABYSSAL LANTERN — a deep-sea survival roguelite. You are Neria, the last lanternfish: survive 5:00 against the dark swarm, gather light, level up and draft your build from 5 weapons and 8 boons, dash through the packs, and slay the Leviathans to light the Garden again. Six enemy types, escalating waves across five abyss tiers, a boss every 90 seconds, and a full loop: title, play, level-up draft, pause, victory and defeat with restart.

## Run it

```sh
npx -y serve game
```

Then open http://localhost:3000 in desktop Chrome. No build step, no network: the game is static files under `game/`, and `main.ts` hands it in (copies `game/` + `screenshots/` to `/output` and writes `dossier.json`).
